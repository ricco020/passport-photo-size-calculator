# Passport photo size calculator

Convert passport and visa photo sizes between millimetres, inches and pixels at any resolution, with a reference table for ten documents (US 2x2 passport and visa, DV lottery, UK, Canada, India, OCI, Australia, Schengen).

Live page: https://ricco020.github.io/passport-photo-size-calculator/

Formula: `pixels = millimetres / 25.4 x dpi`. Data in `specs.csv` and `specs.json` (CC BY 4.0), each row links to the official source. Always read the official page before applying.

Sizes match the ones used by [passportphoto2x2.com](https://passportphoto2x2.com/), a private photo cropping service (not a government site).
